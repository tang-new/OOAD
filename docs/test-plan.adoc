== 隔离与运行前检查

集成基类会 Flyway clean/migrate、恢复表快照并清理 Redis；E2E 会新建 `rbac_e2e_<时间戳>` 数据库并清空 Redis 5号库。
这些是破坏性测试行为，*只能连接本机专用可丢弃实例*，不能指向生产、共享开发库或部署数据卷。
Redis 的逻辑库编号不是实例隔离的替代品。

* 本阶段仅允许127.0.0.1:13306 的测试 MySQL 与127.0.0.1:16379 的测试 Redis，容器端口应只绑定回环；预先核实实例身份、库名和配置，不能只看端口。
* 后端参数：TEST_DB_URL（明确 rbac_test）、TEST_DB_USER、TEST_DB_PASSWORD、TEST_REDIS_HOST、TEST_REDIS_PORT；测试 Redis 默认逻辑库0，仍须独占实例。
* E2E 另核对 E2E_DB_HOST（含端口，如127.0.0.1:13306）、E2E_DB、E2E_DB_USER、E2E_DB_PASSWORD、E2E_REDIS_HOST/PORT，不能因 Java 测试变量已设置就假定 E2E 也隔离。确认全局 setup 将清理专用 Redis 的5号库。
* 使用 Java21，显式核对 JAVA_HOME 与 `java -version`；本机默认 Java8 不可直接使用。前端需 Node20+；口令及 Token 不写入报告、命令示例或仓库。

隔离确认且依赖已就绪后，可在仓库根目录执行以下待运行命令（Windows 使用 mvnw.cmd）：

[source,shell]
----
./mvnw -pl rbac-structured -am verify
cd rbac-web
npm ci
npm run typecheck
npm run test:coverage
npm run build
npm run e2e
----

E2E 读取已构建的 structured jar，并启动后端18081及前端5174；JAVA_BIN 可指定 Java21，PW_CHROMIUM 可指定浏览器。测试配置和夹具以仓库现有文件为准，执行前必须再次核对。

== M2 独立骨架与前端连通

`./mvnw -pl rbac-ddd -am clean verify` 不运行structured集成测试，不需要MySQL/Redis。
骨架21项测试覆盖实际HTTP、健康标识、业务404和跨后端依赖反例，不能拿来代替RBAC1领域测试。

前端 `npm run e2e:m2` 使用独立Playwright配置：启动真实DDD jar和同一Vue前端，仅以RBAC_API选择代理；
不执行一期globalSetup、不建库、不清Redis。桌面/手机均确认health元数据来自DDD，并确认登录POST仍404。
通过 `JAVA_HOME` 或JAVA_BIN选择Java21，通过PW_CHROMIUM选择兼容浏览器；缺浏览器属于环境失败而不是业务RED。
截图在 `docs/evidence/m2/`，已实际打开核查，仅证明登录页呈现及连通，不证明登录业务可用。

工程脚本测试复制到临时目录，以Docker/Maven替身检查默认值、显式环境优先、非法MODULE和旧服务保护；不会读取真实.env或执行发布。
Windows运行Node脚本测试时可用BASH_TEST_SHELL指定实际Git Bash绝对路径，Linux默认使用PATH中的bash。

== 新旧编号与共享黑盒目标

一期 T01–T22 及 b 后缀一律记为 `RBAC0/Txx`，语义仍是旧多公司/scope等。
新验收一律使用 `RBAC1/Txx`、`RBAC1/DAG-*`、`RBAC1/ORG-*`、`RBAC1/API-C*`、`RBAC1/AUD-T*` 等命名空间；相同数字不表示同一需求，也不能复用旧通过结论。

双后端共享黑盒测试尚待建设：共用请求、响应、逻辑夹具和预期，分别对独立启动且数据隔离的 structured/DDD 运行，不共享业务算法。
重点覆盖：

* DAG 多父/传递/菱形/停用切断、跨系统拒绝及并发反向加边防环。
* 部门准入、迁部门只回收不合资格指派、不修改共享角色；系统/audience 隔离。
* 七外部接口精确字段及HTTP码、UI/API权限分离、可信网关与真实课程对象级拒绝。
* requestId 串行/并发重试、同键异体拒绝、审计写失败回滚、成功业务与审计同事务、敏感字段脱敏。
* L1/L2、多副本撤权与延迟回填；双后端前端切换、桌面/手机真实 E2E、三层日志与 Swarm 配置。

DDD业务、教师实际部署契约版本、部署权限和真实联调环境仍有缺口；无法核验项应保留为待验证，不用 Mock 演示或旧测试冒充完成。
每次报告记录用例命名空间、环境、命令/退出码、断言及脱敏产物；一期回归通过不等于RBAC1需求验收通过。
