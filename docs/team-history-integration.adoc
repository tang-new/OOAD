== 必须延续的安全语义

* 撤销前验证当前管理权限、用户管理范围及assignment确实属于路径中的用户；不能仅凭曾授出就越过当前范围。
* 不能撤销最后有效超级管理员；特殊管理员能力不能被空权限集合伪装成可授予的普通角色。
* 关系、授权版本与本地SUCCESS审计同事务；拒绝审计独立提交。
* 两实例预热后撤权，提交后下次请求不得使用旧缓存继续许可。
* 启用/继承/指派同样检查授权上界；调动只清理该用户不再准入的指派，不改共享角色权限。
* 本次仍保留真实反例与故障注入，不用“方法存在”或“源码净差异仅注释”替代运行验收。
