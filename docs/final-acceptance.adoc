== 安全与限制

没有默认公开root口令、JWT角色claim、浏览器服务key、真实员工表或生产数据迁移。
新基线只用于空开发库，未改旧rbac_test或生产库/旧迁移；所有自动化只清本次自有资源，未动其它容器或数据卷。
本地TLS自签，当前只证明授权本机单manager，不据此声称外网信任或外部服务器运行。
同步审计保持明确跨库未确认窗口；没有引入MQ/Outbox，也没有把日志幂等伪装成整个业务请求幂等。
未提供的新版评分原件、课堂OO设计PPT及外部部署条件仍需真实核验，不编造验收。
