== 固定范围

单公司；用户唯一所属部门；部门只承担组织管理和直接角色指派准入。
角色权限不带业务数据部门范围；移部门不修改共享角色定义，只回收不合资格指派。
角色继承为同系统 senior→junior DAG，支持多父、传递、菱形去重、停用节点切断和并发防环。
UI菜单/按钮树与角色DAG是两种模型；API独立登记并显式映射，默认拒绝。
权限中心保存统一身份和集中审计；课程业务的对象级授权仍由课程Service负责。

不实现RBAC2/3、热力图、风险看板、临时授权、业务数据范围、多租户及课程业务副本。

== 必须同外部行为、不同内部职责的六组设计

S01角色继承加边验环；S02部门准入角色指派；S03有效角色权限闭包；
S04课程API网关鉴权；S05审计幂等同步写入；S06敏感业务和审计同事务。
两后端外部契约、数据库逻辑和业务结果一致；结构化规则在Service，DDD规则在领域对象/策略，应用层只编排。
当前只锁定用例，尚未生成与不存在的代码相冒充的类图。
