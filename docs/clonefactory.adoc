== 固定源码安装

本项目使用教师提供的编译期注解处理器 `cn.edu.xmu:clonefactory:0.0.2`。
根 POM 的 `clonefactory.version` 同时控制结构化和 DDD 模块依赖及注解处理器路径。独立 smoke 项目也使用 0.0.2。
固定的上游提交是 `e0c2b1e54b29207f13088b80eb7e49c22152fdcf`，`clonefactory` 子树是 `1a5158cb19357df59068af279875052bae1917d0`。
link:https://gitee.com/mingqcn/spring-fundamentals/tree/e0c2b1e54b29207f13088b80eb7e49c22152fdcf/clonefactory[教师源码]

配置 JDK 21 后在仓库根目录运行。Windows 使用 Git Bash。

[source,bash]
----
bash tools/install-clonefactory.sh
bash mvnw -B -ntp -s tools/clonefactory-smoke/settings.xml \
  -gs tools/clonefactory-smoke/settings.xml \
  -f tools/clonefactory-smoke/pom.xml clean test
bash mvnw -B -ntp -pl rbac-structured,rbac-ddd -am clean test
----

脚本默认将固定提交保存到仓库外的 `$HOME/.cache/ooad-clonefactory-0.0.2/reference`。
可以通过 `CLONEFACTORY_CACHE` 更改仓库外缓存路径，或以 `CLONEFACTORY_SOURCE` 指向 HEAD 在固定提交的干净参考仓库。
脚本校验 Git 子树并仅导出该模块的跟踪文件，使用原始 POM 在临时目录执行 `clean install`。
依赖从 HTTPS Maven Central 解析。若使用 `-Dmaven.repo.local`，安装、smoke 和业务编译应使用同一 Maven 仓库。

== 业务映射

* 结构化模块把 `DisplayName` record 复制到 `NameChange` record，保留模板中可信的 ID 和操作者。
  五个创建入口用 record 访问器填充实体的公共字段，由服务解析系统、上级机构和部门并设置状态、口令哈希等可信字段。
* DDD 的角色请求、角色及 UI 公开响应和持久化快照使用 record。UI 的 `children` 由 REST 边界组装。
  系统标识、权限关联与默认值由持久化适配器补齐，角色聚合仍通过自己的构造器恢复。
* 普通 `copy(target, source)` 会复制允许的空值。对可显式清空的 PATCH，DTO 记录字段存在性，再由用例应用相应语义。
  `copyNotNull(target, source)` 用于省略空值表示保留模板的场景，零与 false 都是有效值。
* record 目标通过规范构造器生成新实例，必须使用返回值。普通类的 `final` 目标要求合适的公共全参数构造器，参数名须能匹配属性。
  公共字段和标准 JavaBean `getX()/setX()` 可参与映射。字段需要类型一致，派生或类型转换由调用方处理。
* 使用目标形状和具体方向的字段排除约束复制范围。复制是浅赋值。注解处理器依赖 JavaPoet 和 AutoService，模块必须按 POM 保留传递依赖。

== 验证生成结果

`clean test` 会重新生成各模块下的
`target/generated-sources/annotations/cn/edu/xmu/clonefactory/util/CloneFactory.java`。
验收检查源码中的 record 访问器、构造器和公共字段访问，并验证字段值、身份和凭据排除、模板回退与 PATCH 空值语义。
独立 smoke 还覆盖原 JavaBean 重载、`copyNotNull` 的 null/0/false 以及 `final` 目标。
教师编码规范压缩包中的旧版 record 与 final 限制对应先前处理器，其字段白名单和 clean build 验证要求仍适用。
