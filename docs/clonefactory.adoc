== 安装

从仓库根目录运行：

[source,bash]
----
export JAVA_HOME='D:/Software/Eclipse Adoptium/jdk-21.0.7.6-hotspot'
export PATH="$JAVA_HOME/bin:$PATH"
LOG_DIR='C:/Users/vintces/Downloads/rbac1-context-extracted'
mkdir -p "$LOG_DIR"
bash tools/install-clonefactory.sh > "$LOG_DIR/clonefactory-install.log" 2>&1
----

默认克隆到仓库外 `$HOME/.cache/ooad-clonefactory/reference`，检出固定提交；
`CLONEFACTORY_CACHE` 可以指定其他仓库外缓存目录。缓存提交不匹配时失败，不自动覆盖或修复工作区。
首次需要访问 Gitee 和 Maven Central；复用匹配缓存时不再拉取 Git。

已有匹配参考源码时，可在安装前设置（目录可为仓库根目录或其中的 clonefactory 子目录）：

[source,bash]
----
export CLONEFACTORY_SOURCE='C:/Users/vintces/Downloads/rbac1-context-extracted/spring-fundamentals-reference/clonefactory'
bash tools/install-clonefactory.sh > "$LOG_DIR/clonefactory-install.log" 2>&1
# 恢复默认克隆模式：unset CLONEFACTORY_SOURCE
----

脚本核验 HEAD、clonefactory tree hash，并拒绝 clonefactory 下相对固定提交的已跟踪修改。
仅用 `git archive` 导出该提交的 clonefactory 跟踪文件至仓库外临时目录；不复制参考仓库的
用户配置、凭据、`.git`、未跟踪文件或已有 target，也不在参考目录编译。
构建完成或失败都会清理临时导出目录。脚本没有 push 操作。

使用根 Wrapper 对导出的原始 POM 执行 `clean install`，安装至默认本地 `~/.m2/repository`；
可以追加 Maven 参数，例如 `-Dmaven.repo.local=...`（smoke 必须使用同一个本地仓库）。
脚本生成无凭据 Maven settings，同时传入 `-s` 和 `-gs`，屏蔽原 POM 的 Spring milestone/
HTTP 镜像并统一走 HTTPS Maven Central，不读取/复制其他项目的 settings。
下载代理需求应通过自己的执行环境处理，勿把凭据加入本仓库。

注意：固定的是源码提交及工具链，非上游 SNAPSHOT 的远程发布保证。安装会替换本地同坐标 SNAPSHOT。
上游 POM 未固定 compiler/Boot 插件版本，Maven 会警告；本次 Maven 3.9.9 选择 compiler 3.13.0，
Boot 插件没有绑定到生命周期，不执行 repackage，也不需要升级本项目 Boot。
未改写上游 POM，不声称产物 ZIP 时间戳或字节级 hash 可重复。

== 独立编译与 JUnit 验证

安装成功后运行：

[source,bash]
----
bash mvnw -B -ntp \
  -s tools/clonefactory-smoke/settings.xml \
  -gs tools/clonefactory-smoke/settings.xml \
  -f tools/clonefactory-smoke/pom.xml clean verify \
  > "$LOG_DIR/clonefactory-smoke.log" 2>&1
----

`settings.xml` 是本工具公开的无凭据 Central 镜像配置，不是用户配置的副本。
smoke POM 无 parent，Java release 21，compiler 3.13.0、Surefire 3.5.2、JUnit Jupiter 5.11.4；
依赖采用 `provided`，处理器路径显式声明，不依赖隐式 classpath 扫描：

[source,xml]
----
<dependency>
  <groupId>cn.edu.xmu</groupId>
  <artifactId>clonefactory</artifactId>
  <version>0.0.1-SNAPSHOT</version>
  <scope>provided</scope>
</dependency>
<!-- maven-compiler-plugin/configuration 内 -->
<release>21</release>
<annotationProcessorPaths>
  <path>
    <groupId>cn.edu.xmu</groupId>
    <artifactId>clonefactory</artifactId>
    <version>0.0.1-SNAPSHOT</version>
  </path>
</annotationProcessorPaths>
<annotationProcessors>
  <annotationProcessor>cn.edu.xmu.clonefactory.CopyProcessor</annotationProcessor>
</annotationProcessors>
----

测试直接导入真实生成的 `cn.edu.xmu.clonefactory.util.CloneFactory`。
没有手写替代类，未提交生成源码。`clean` 会删除旧产物，处理器必须重新生成才能通过编译。
所有 Bean 都有明确的同名私有字段及 public `getX/setX`，不使用 Lombok 或 record。

6 个 JUnit 测试覆盖：

. `CopyFrom` 同名字段复制、返回目标实例、请求 password 被 Exclude 后保留原值。
. `CopyTo` 输出普通字段，敏感字段既不覆盖哨兵值，也不泄漏到新建 View。
. `CopyNotNullFrom` 使用 Long/Integer/Boolean 包装类型；null 保留旧值，0/false 仍复制，敏感字段排除。
. `CopyNotNullTo` 的 null 保留与 0/false 更新。
. Domain -> StoredBean -> Domain roundtrip 保留所有字段，包括可信持久化 password；实例独立。
. 普通 `copy` 会用 null 覆盖，区别于 `copyNotNull`。

产物位置：

* `tools/clonefactory-smoke/target/generated-sources/annotations/cn/edu/xmu/clonefactory/util/CloneFactory.java`
* `tools/clonefactory-smoke/target/classes/cn/edu/xmu/clonefactory/util/CloneFactory.class`

== 使用限制

* 上游直接依赖 `com.squareup:javapoet:1.13.0` 和 `com.google.auto.service:auto-service:1.1.1`；
  Maven 从安装的原始 POM 解析其传递依赖，处理器路径也包含这些依赖。
  JavaPoet 负责生成 Java 源码，AutoService 在构建处理器时生成 SPI 注册文件。
  仅复制 JAR 却漏掉 POM/传递依赖，可能导致处理器加载失败。
* 不支持 record accessor（`name()`）或 immutable record 构造映射；实现按 `getName()/setName()`
  匹配，跳过 final/static 字段。Boolean 也使用 `getEnabled()`，不能假定识别 `isEnabled()`。
* 请声明真实同名字段与可访问、签名兼容的 JavaBean 方法。只有方法没有字段的“虚拟字段”分支
  存在方法名再拼 getter/setter 的风险，本验证不把它当成可靠接口；不支持任意字段改名或自动类型转换。
* `copyNotNull` 对 getter 返回值生成 `null != ...`，因此用包装类型，不可直接用于基本类型属性；
  它也无法表达“显式清空字段”，集合/嵌套对象是普通赋值，不是深拷贝。
* Exclude 必须匹配具体复制方向与来源/目标类型；本例放在字段上。
  上游方法注解合并逻辑主要读取 CopyFrom 系列，不应推断所有方向的方法级 Exclude 等价。
* 生成方法是 `copy(target, source)` / `copyNotNull(target, source)`，目标对象由调用方创建。
  源或目标为 null 没有自动防护，重复声明同一映射方向可能产生重复重载；不要同时在两端重复声明。
* 每次编译输出固定 util.CloneFactory；不要跨编译批次拼接手写同名类。
  本次只验证独立 Bean 场景，不代表已验证业务集成、Lombok 处理顺序或已有系统全部回归。
