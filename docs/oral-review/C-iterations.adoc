关键数据库后置条件已经实际核对：

* 被拒绝的继承边不存在；权限/状态/部门保持请求前事实；全局授权版本和SUCCESS审计不增加。
* 并发A→B和B→A返回200/409，胜方可以不同；最终恰好一条边，方向必须与本轮200请求一致，版本与SUCCESS各只推进一次。
* 专用库审计BEFORE INSERT触发器抛错时HTTP503；新边为0，授权版本和SUCCESS计数不变；触发器在finally删除。
* 删除角色后，sys_role、sys_role_permission、sys_user_role、sys_department_allowed_role、sys_role_hierarchy五表相关行均为0。
* 合法64字符角色码、0/1/1000原始权限项、范围内重复值去重仍被接受；1001项在HTTP边界拒绝。
